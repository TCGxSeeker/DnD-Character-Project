# Security policy

## Supported versions

Security fixes are applied to the latest published release and the `main` branch.

## Reporting a vulnerability

Do not publish credentials, personal character exports, or exploit details in a public issue. Use the repository owner's private GitHub contact or a GitHub private vulnerability report when that feature is enabled.

Include the affected version, operating system or browser, reproduction steps, and the impact. Do not include real personal data in a reproduction file.

Arcane Observatory intentionally stores character data locally and does not require an account, telemetry service, API key, or remote database. Open5e is the only approved runtime reference-data provider.
